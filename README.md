# X / PayPay 手動販売用・安全な動画配布

PayPayの個人間送金を販売者が手動確認した後、Discordの管理パネルからXのDMへ送る動画リンクを即時発行するCloudflare Workerです。

## 最短の販売手順

1. 購入者とXのDMで商品・金額を確認する。
2. PayPayで入金を確認する。
3. Discord販売チャンネルの **「送信用リンクを発行」** を押す。
4. 動画を選ぶ。
5. 表示されたリンクをそのままXのDMへ貼り付ける。

購入者はリンクを開くだけで動画を受け取れます。動画を端末へダウンロードしてからXへ再アップロードする必要はありません。

## 安全設計

- リンク発行は `OWNER_DISCORD_ID` の管理者だけが実行できます。
- 配布ファイルはR2で非公開のままです。
- 発行リンクは24時間で失効し、最大3回までダウンロードできます。
- リンクには購入者名・PayPay情報・注文内容を含めません。
- PayPayの暗証番号、ログイン情報、リンクのパスワードはBotへ入力しません。
- Stripe・自動課金は使いません。

## 初回反映

管理パネルは最大15分以内に旧販売パネルと自動置換されます。新しいD1テーブルも、最初に管理者がリンクを発行した時点で自動作成されます。

## 運用上の注意

この仕組みは正規に販売できる自作・許諾済みのデジタルコンテンツだけに使用してください。リンクはPayPayの入金を確認してから発行し、XのDMで購入者本人へ送ってください。
